1(a) Simple Linear Regression (Head Size vs. Brain Weight) ex01a_linear_regression.py 
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split

# Load dataset
data = pd.read_csv("../MLdatasets/headbrain.csv")
print(data)

X = data["Head Size(cm^3)"]
y = data["Brain Weight(grams)"]

# Split into training and testing sets (33% test)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.33, random_state=42)

# Train Linear Regression model
model = LinearRegression()
model.fit(np.expand_dims(X_train, axis=1), np.expand_dims(y_train, axis=1))
predictions = model.predict(np.expand_dims(X_test, axis=1))

# Plot scatter points and regression line
plt.figure(figsize=(8, 5))
plt.scatter(X_test, y_test, color="r", label='Scatter Plot')
plt.plot(X_test, predictions, color="b", label='Regression Line')
plt.xlabel('Head Size in cm3')
plt.ylabel('Brain Weight in grams')
plt.legend()
plt.show()

# Error Estimation (RMSE & R2 Score)
r2_score = model.score(np.expand_dims(X_test, axis=1), np.expand_dims(y_test, axis=1))
mse = mean_squared_error(y_test, predictions)
print(f"RMSE VALUE : {np.sqrt(mse)}\nR2 SCORE : {r2_score}")

Key Concepts & Formulas

  • Simple Linear Regression models a linear relationship between input x and output y: y = β₀ + β₁x, where β₁ is the slope (scale factor) and β₀ is the bias (intercept).
  • Ordinary Least Squares (OLS) minimizes the sum of squared residuals: β₁ = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)² and β₀ = ȳ - β₁x̄.
  • Evaluation Metrics: Root Mean Squared Error RMSE = √[ (1/m) Σ(ŷᵢ - yᵢ)² ] and R² Score = 1 - (SS_r / SS_t).
  • Logistic Regression predicts binary class probabilities using the Sigmoid (Logistic) function: p = 1 / (1 + e⁻ʸ), estimated via Maximum Likelihood Estimation (MLE).

Lab Exam Viva Questions

Q1. What is the main difference between Linear and Logistic Regression?

Ans: Linear Regression predicts continuous unbounded numerical outputs using Ordinary Least Squares (OLS), whereas Logistic Regression predicts discrete class probabilities (0 or 1) using the Sigmoid function and Maximum Likelihood Estimation (MLE).

Q2. What does an R² score close to 1 indicate?

Ans: An R² score close to 1 indicates that the regression model explains a high proportion of the variance in the dependent variable.

Q3. Why do we use a Confusion Matrix in Logistic Regression?

Ans: A confusion matrix summarizes true positives, true negatives, false positives, and false negatives class-wise to compute precision, recall, F1-score, and accuracy.

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import multivariate_normal

def generate_surface(mean, cov):
    x, y = np.linspace(-5, 5, 100), np.linspace(-5, 5, 100)
    x1, x2 = np.meshgrid(x, y)
    pos = np.dstack((x1, x2))
    pdf = multivariate_normal(mean=mean, cov=cov).pdf(pos)
    return x1, x2, pdf

distributions = [
    (np.array([0, 0]), np.eye(2)),
    (np.array([0, 0]), np.array([[1, -0.1], [-0.8, 1]]))
]

fig, ax = plt.subplots(1, 2, figsize=(13, 5))
plt.suptitle("Bivariate Normal Distributions")
ax[0].set_title("Independent Variables")
ax[1].set_title("Correlated Variables")

for i, dist in enumerate(distributions):
    x1, x2, pdf = generate_surface(dist[0], dist[1])
    con = ax[i].contourf(x1, x2, pdf, 100, cmap='rainbow')
    ax[i].set_xlabel("$x_1$", fontsize=13)
    ax[i].set_ylabel("$x_2$", fontsize=13)
    ax[i].axis([-3.5, 3.5, -3.5, 3.5])
    c_bar = fig.colorbar(con, ax=ax[i])
    c_bar.ax.set_ylabel("$P(x_1, x_2)$", fontsize=13)

plt.show()

Key Concepts & Formulas

  • Univariate Gaussian PDF: P(x) = [1 / (σ√(2π))] * exp( -½ ((x - μ)/σ)² ), characterized by mean μ and variance σ².
  • The univariate normal curve is bell-shaped and symmetrical about its mean x = μ, where its peak value is 1 / (σ√(2π)).
  • Multivariate Gaussian PDF in d-dimensions: P(x) = [1 / (√( (2π)ᵈ |Σ| ))] * exp( -½ (x - μ)ᵀ Σ⁻¹ (x - μ) ).
  • Here μ is the d-component mean vector and Σ is the d×d covariance matrix.

Lab Exam Viva Questions

Q1. What determines the width and peak height of a univariate Gaussian curve?

Ans: The standard deviation (σ) determines the width (spread) of the bell curve, and the peak height at x = μ is given by 1 / (σ√(2π)).

Q2. What happens to bivariate Gaussian contours when two variables are uncorrelated vs. correlated?

Ans: When variables are independent with equal variance, the contours are circular. When they are correlated, the off-diagonal covariance terms tilt the contours into diagonal ellipses.

Q3. What is the role of the covariance matrix Σ in multivariate Gaussian density?

Ans: Σ captures the variance of each dimension along its diagonal and the pairwise linear correlations between dimensions in its off-diagonal elements.

Key Concepts & Formulas

  • Curse of Dimensionality: As the number of features increases, model performance can degrade and computational cost rises.
  • PCA constructs orthogonal (uncorrelated) linear combinations of original variables called Principal Components (Eigenvectors) that capture maximal variance.
  • PCA Algorithm: (1) Center data by subtracting the mean vector, (2) Compute d×d covariance matrix, (3) Compute eigenvalues & eigenvectors, (4) Sort and pick top m eigenvectors with largest eigenvalues, (5) Project data onto the m eigenvectors.

Lab Exam Viva Questions

Q1. Why should we standardize data using StandardScaler before applying PCA?

Ans: PCA maximizes variance along projection axes. Without standardization, features with larger numerical scales (e.g., area vs smoothness) would dominate the first principal component.

Q2. What do eigenvalues and eigenvectors represent in PCA?

Ans: Eigenvectors represent the principal directions (axes) of maximum variance, while eigenvalues represent the magnitude of variance captured along each corresponding eigenvector.

Q3. Are Principal Components correlated with each other?

Ans: No, principal components are mutually orthogonal, meaning the correlation between any two distinct principal components is zero.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.cluster import KMeans as sklKMeans
from sklearn.metrics import silhouette_score

data = pd.read_csv("../MLdatasets/Iris.csv")
X = data[["SepalLengthCm", "PetalLengthCm"]]

def kMeans(X, k):
    distortion = []
    for i in range(1, k + 1):
        model = sklKMeans(n_clusters=i, init='random', n_init='auto', max_iter=10).fit(X.values)
        distortion.append(model.inertia_)
    print(f"Silhoutte Score for {k} cluster is {silhouette_score(X, model.labels_)}")
    return model, distortion

k = 5
model, distortion = kMeans(X, k)

centroids = model.cluster_centers_
index = model.labels_

plt.figure(figsize=(14, 7))

import numpy as np
import matplotlib.pyplot as plt
from sklearn.mixture import GaussianMixture

def gen_data(k=3, dim=2, points_per_cluster=2000, lim=[-10, 10]):
    x = []
    mean = np.random.rand(k, dim) * (lim[1] - lim[0]) + lim[0]
    for i in range(k):
        cov = np.random.rand(dim, dim + 10)
        cov = np.matmul(cov, cov.T)
        _x = np.random.multivariate_normal(mean[i], cov, points_per_cluster)
        x += list(_x)
    x = np.array(x)
    if (dim == 2):
        fig = plt.figure()
        ax = fig.gca()
        ax.scatter(x[:, 0], x[:, 1], s=3, alpha=0.4)
        ax.autoscale(enable=True)
    return x

data = gen_data()

gmm = GaussianMixture(n_components=3)
gmm.fit(data)

plt.figure(figsize=(8, 6))
plt.scatter(data[:, 0], data[:, 1], s=3)
for covar, mean in zip(gmm.covariances_, gmm.means_):
    v, w = np.linalg.eigh(covar)
    angle = np.arctan2(w[0][1], w[0][0])
    angle = 180 * angle / np.pi
    v = 2.0 * np.sqrt(2.0) * np.sqrt(v)
    ell = plt.matplotlib.patches.Ellipse(
        mean, v[0], v[1], 180 + angle, color='r', alpha=0.3
    )
    plt.gca().add_patch(ell)

plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.title('Gaussian Mixture Model')
plt.show()

Key Concepts & Formulas

  • k-Means partitions data into k non-overlapping clusters by minimizing within-cluster sum of squared Euclidean distances (inertia) to centroids.
  • Gaussian Mixture Model (GMM) represents data as a weighted superposition of M Gaussian densities: P(x|w) = Σ α_k P(x|w_k), where Σ α_k = 1.
  • EM Algorithm for GMM: E-Step computes posterior membership weights w_ik for each data point; M-Step updates mixture weights α_k, mean vectors μ_k, and covariance matrices Σ_k.

Lab Exam Viva Questions

Q1. Why can GMM outperform k-Means on certain datasets?

Ans: k-Means assumes spherical clusters of similar size and performs hard assignment based on Euclidean distance. GMM uses soft probabilistic assignment and full covariance matrices, allowing it to model elongated, elliptical, and overlapping clusters.

Q2. What is the Elbow Method in k-Means?

Ans: The Elbow Method plots cluster distortion (inertia) against the number of clusters k. The 'elbow' point where the rate of decrease sharply levels off indicates the optimal k.

Q3. What happens in the E-step and M-step of GMM training?

Ans: In the E-step (Expectation), the algorithm calculates the probability (membership weight) that each data point belongs to each Gaussian cluster. In the M-step (Maximization), it updates each Gaussian's weight, mean, and covariance using those membership weights.

# Decision Boundary Helper Function
def plotq(model, X, y):
    x_min, x_max = X[:, 0].min() - 0.1, X[:, 0].max() + 0.1
    y_min, y_max = X[:, 1].min() - 0.1, X[:, 1].max() + 0.1
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100), np.linspace(y_min, y_max, 100))
    x_in = np.c_[xx.ravel(), yy.ravel()]
    y_pred = model.predict(x_in)
    if len(y_pred[0]) > 1:
        print("doing multiclass classification")
        y_pred = np.argmax(y_pred, axis=1).reshape(xx.shape)
    else:
        print("doing binary")

Key Concepts & Formulas

  • Backpropagation Neural Network (BPNN) is a multilayer feedforward network that propagates error backward from the output layer to hidden layers to update weights via gradient descent.
  • Support Vector Machine (SVM) is based on Structural Risk Minimization (SRM) and finds the optimal hyperplane g(x) = wᵀx + b = 0 that maximizes the margin 2 / ||w|| between classes.

Lab Exam Viva Questions

Q1. What are Support Vectors in SVM?

Ans: Support vectors are the training data points that lie closest to the decision hyperplane (on the maximal margin boundaries). They directly determine the orientation and position of the hyperplane.

Q2. What is the effect of the C and Gamma parameters in SVM?

Ans: C is the regularization parameter controlling the trade-off between a smooth decision boundary and classifying training points correctly. Gamma defines how far the influence of a single training sample reaches (low = far, high = close).

Q3. Why did we use ReLU in hidden layers and Sigmoid in the output layer of BPNN?

Ans: ReLU enables non-linear feature learning without vanishing gradients in hidden layers, while Sigmoid squashes the final output to [0, 1] for binary classification probability.

Key Concepts & Formulas

  • A CNN consists of two primary building blocks: the Convolution Block (Conv2D + Pooling for feature extraction) and the Fully Connected Block (Flatten + Dense + Softmax for classification).
  • Output Dimension Formula (Valid Padding): output_shape = (input_shape - pool_size + 1) / strides.
  • Activation Functions: ReLU f(x) = max(0, x) introduces non-linearity; Softmax y = e^x / Σe^x converts final logits into a probability distribution summing to 1.

Lab Exam Viva Questions

Q1. What is the purpose of MaxPooling2D in a CNN?

Ans: MaxPooling2D downsamples the spatial dimensions (height and width) by taking the maximum value in each window, reducing computation, memory usage, and overfitting.

Q2. What is the difference between 'valid' and 'same' padding in Conv2D?

Ans: 'valid' means no zero-padding is added, so spatial dimensions shrink after convolution. 'same' pads the borders with zeros so the output height and width match the input (when stride=1).

Q3. Why do we divide pixel values by 255 before training?

Ans: Dividing by 255 normalizes 8-bit grayscale pixel intensities from [0, 255] to the [0, 1] range, which stabilizes gradient descent and speeds up convergence.

Key Concepts & Formulas

  • Recurrent Neural Networks (RNNs) contain feedback loops that allow information to persist across time steps, making them suitable for sequential and time-series data.
  • Standard RNNs suffer from the vanishing/exploding gradient problem over long-term dependencies.
  • Long Short-Term Memory (LSTM) networks (Hochreiter & Schmidhuber, 1997) solve this using a conveyor-belt Cell State (C_t) regulated by three sigmoid gates: Forget Gate (f_t), Input Gate (i_t), and Output Gate (o_t).

Lab Exam Viva Questions

Q1. What are the three gates in an LSTM cell and what do they do?

Ans: 1. Forget Gate (f_t): decides what information to discard from the cell state. 2. Input Gate (i_t): decides which new candidate values (C̃_t) to store in the cell state. 3. Output Gate (o_t): decides what filtered part of the cell state to output as h_t.

Q2. Why did we set shuffle=False in train_test_split for sequence prediction?

Ans: For sequential and time-series problems, preserving temporal order is important so the model trains on earlier sequence values and tests on future unseen values.

Q3. What input shape does a Keras LSTM layer expect?

Ans: A 3D tensor of shape (batch_size, timesteps, features). In this experiment, each sample is reshaped to (1, 1) representing 1 time step and 1 feature.

import numpy as np
import librosa
from sklearn.model_selection import train_test_split
import tensorflow as tf

from IPython.display import Audio, display

data_path = "./datasets/isolated_word_dataset"
labels = np.array(["bed", "cat", "happy"])
n_classes = labels.shape[0]
n_mfcc = 12  # no. of mfc coefficients
t = 30       # no. of time windows on which the mfc coefficients are computed
input_shape = (-1, n_mfcc, t, 1)

# 1. Extract MFCC Features from WAV Audio
def wav2mfcc(file, t, n_mfcc):
    data, sr = librosa.load(file, sr=None)
    mfcc = librosa.feature.mfcc(y=data, sr=sr, n_mfcc=n_mfcc)
    if mfcc.shape[1] > t:
        mfcc = mfcc[:, :t]
    if mfcc.shape[1] < t:
        mfcc = np.pad(mfcc, pad_width=((0, 0), (0, t - mfcc.shape[1])))
    return mfcc

def load_speech_dataset_features(data_path, labels):
    X, y = [], []
    for i, label in enumerate(labels):
        file_name = f"{data_path}/{label}.npy"
        try:
            data = np.load(file_name)
        except FileNotFoundError:
            data = np.array([
                wav2mfcc(file, t=t, n_mfcc=n_mfcc)
                for file in librosa.util.find_files(f"{data_path}/{label}/")
            ])
            np.save(file_name, data)
        X.append(data)
        y.append(np.full((data.shape[0], 1), i))
    X = np.vstack(X).reshape(input_shape)
    y = np.vstack(y) == np.arange(n_classes)  # one-hot encoded
    return X, y

X, y = load_speech_dataset_features(data_path, labels)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 2. Build CNN Model for Spectrogram/MFCC Classification
def get_model():
    model = Sequential()
    model.add(Conv2D(32, kernel_size=(2, 2), activation='relu', input_shape=(n_mfcc, t, 1)))
    model.add(Conv2D(48, kernel_size=(3, 3), activation='relu'))
    model.add(Conv2D(64, kernel_size=(4, 4), activation='relu'))
    model.add(MaxPooling2D(pool_size=(4, 4)))
    model.add(Dropout(0.25))
    model.add(Flatten())
    model.add(Dense(128, activation='relu'))
    model.add(Dropout(0.25))
    model.add(Dense(64, activation='relu'))
    model.add(Dropout(0.3))
    model.add(Dense(n_classes, activation='softmax'))
    model.compile(
        loss=CategoricalCrossentropy(),
        optimizer=Adadelta(0.3),
        metrics=['accuracy']
    )
    return model

tf.random.set_seed(0)
model = get_model()
print(model.summary())

# 3. Train Model
model.fit(
    X_train, y_train,
    batch_size=50,
    epochs=50,
    verbose=True,
    validation_data=(X_test, y_test)

Key Concepts & Formulas

Q2. What is a Spectrogram?

Ans: A spectrogram is a 2D visual representation of an audio signal showing how frequency amplitudes (represented by color intensity) vary over time.

Q3. What are the four main types of speech recognition systems?

Ans: 1. Isolated Words (pauses required between words), 2. Connected Words, 3. Continuous Speech (natural dictation), and 4. Spontaneous Speech (unrehearsed speech with fillers).

    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

    # Detect the faces
    faces = face_cascade.detectMultiScale(gray, 1.1, 4)

    # Draw the rectangle around each face
    for (x, y, w, h) in faces:
        cv2.rectangle(img, (x, y), (x + w, y + h), (0, 0, 255))

    # Display
    cv2.imshow('img', img)

    # Press Key Q to quit and Close window
    if cv2.waitKey(1) & 0xFF == ord('q'):
        # Release the VideoCapture object
        cap.release()
        # Close all window
        cv2.destroyAllWindows()
        break

Key Concepts & Formulas

  • The Viola-Jones algorithm (2001) has four stages: (1) Haar Feature Selection, (2) Creating an Integral Image, (3) AdaBoost Training, and (4) Cascading Classifiers.
  • Haar Features compute the difference between the sum of pixels under black and white rectangles: Δ = (1/n)Σ I_dark - (1/n)Σ I_white.
  • Integral Image (summed-area table) allows the sum of pixels in any rectangular region to be computed in constant time using just 4 corner lookups.
  • Cascade of Classifiers groups 6000+ AdaBoost-selected features into 38 stages so background windows are discarded immediately in the first few stages.

Lab Exam Viva Questions

Q1. Why do we convert BGR video frames to Grayscale before running Haar Cascade detection?

Ans: Haar features rely on luminance (light vs dark pixel intensity differences, such as the eye region being darker than the nose bridge), so grayscale reduces computation by 3x without losing structural contrast.

Q2. How does an Integral Image speed up Haar feature calculation?

Ans: In an integral image, each pixel holds the sum of all pixels above and to its left. Any rectangular sum can then be evaluated using only 4 array references instead of looping over every pixel.

Q3. What do the parameters 1.1 and 4 mean in detectMultiScale(gray, 1.1, 4)?

Ans: 1.1 is the scaleFactor (reduces image size by 10% at each scale pyramid step to detect faces of different sizes), and 4 is minNeighbors (minimum overlapping detections required to retain a face box).

import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.datasets import cifar10
from tensorflow.keras.utils import to_categorical
from tensorflow.keras import Sequential
from tensorflow.keras.optimizers import SGD
from tensorflow.keras.layers import Dense, Dropout, Conv2D, MaxPool2D, Flatten
from tensorflow.keras.callbacks import Callback, ModelCheckpoint, EarlyStopping
from tensorflow import random
import joblib
import pandas as pd

# 1. Load CIFAR-10 Dataset
(X_train, y_train), (X_test, y_test) = cifar10.load_data()
cifar_classes = np.array([
    'airplane', 'automobile', 'bird', 'cat', 'deer',
    'frog', 'dog', 'horse', 'ship', 'truck'
])

plt.figure(figsize=(10, 10))

plt.show()

# 3. One-Hot Encode & Normalize Pixels
y_train = to_categorical(y_train, num_classes=10)
y_test = to_categorical(y_test, num_classes=10)
X_train = X_train.astype('float32') / 255
X_test = X_test.astype('float32') / 255

print(f"Shape of training data:\nX-train_shape={X_train.shape} , y-train_shape={y_train.shape}")
print(f"Shape of testing data:\nX-test_shape={X_test.shape} , y-test_shape={y_test.shape}")

# 4. Build CNN Model
def get_model():
    model = Sequential()
    model.add(Conv2D(25, kernel_size=(3, 3), strides=(1, 1), padding='same', activation='relu', input_shape=(32, 32, 3)))
    model.add(Conv2D(50, kernel_size=(3, 3), strides=(1, 1), padding='same', activation='relu'))
    model.add(MaxPool2D(pool_size=(2, 2)))
    model.add(Dropout(0.25))

    model.add(Conv2D(70, kernel_size=(3, 3), strides=(1, 1), padding='same', activation='relu'))
    model.add(MaxPool2D(pool_size=(2, 2)))
    model.add(Dropout(0.25))

    model.add(Flatten())
    model.add(Dense(500, activation='relu'))
    model.add(Dropout(0.4))
    model.add(Dense(250, activation='relu'))
    model.add(Dropout(0.3))
    model.add(Dense(10, activation='softmax'))

    model.compile(loss='categorical_crossentropy', metrics=['accuracy'], optimizer='adam')
    return model

random.set_seed(0)
model = get_model()
print(model.summary())

# 5. Train with ModelCheckpoint and EarlyStopping
checkpoint = ModelCheckpoint("./model/cifar10_epo_cnn.h5", monitor='val_accuracy', mode='max', save_best_only=True)
early_stop = EarlyStopping(monitor="val_accuracy", patience=5, mode="max")
call_backs = [early_stop, checkpoint]

history = model.fit(
    X_train, y_train,
    batch_size=32,
    epochs=50,
    verbose=True,
    validation_split=0.2
)
model.save("./models/cifar10_epo_cnn.h5")

Key Concepts & Formulas

  • Classical Computer Vision relied on manual feature descriptors (SIFT, SURF, BRIEF, HOG, Hough transforms) combined with Bag-of-Words and shallow classifiers like SVM or KNN.
  • Modern Deep Learning performs end-to-end representation learning where hierarchical convolutional filters automatically learn edges, textures, parts, and object classes directly from raw RGB pixels.
  • Dropout randomly zeroes a fraction of neuron activations during training (e.g., 0.25, 0.4, 0.3) to prevent co-adaptation and reduce overfitting.

Lab Exam Viva Questions

Q1. What is the difference between classical feature-based object recognition and Deep Learning CNNs?

Ans: Classical methods require manual feature engineering (e.g., SIFT, SURF, HOG) followed by a separate classifier. Deep Learning CNNs learn hierarchical features and classification end-to-end directly from raw image pixels.

Q2. How do EarlyStopping and ModelCheckpoint callbacks help during training?

Ans: EarlyStopping halts training when validation accuracy stops improving for 'patience' epochs, saving time and preventing overfitting. ModelCheckpoint automatically saves the weights of the best-performing epoch.

Q3. Why does the Flatten layer have 4,480 units in this CIFAR-10 model?

Ans: The input 32×32 image is downsampled twice by 2×2 MaxPooling layers (32 -> 16 -> 8) with 70 filters in the last Conv2D layer, resulting in 8 × 8 × 70 = 4,480 features.
